# ComfyUI-Henge

The ComfyUI nodes behind [Henge](https://github.com/alisson-anjos/Henge), an open-source video studio on MiniMax H3
(character swap, motion transfer, head swap, sharpness). Install from the Comfy Registry (`comfy node install
comfyui-henge`) or clone into `custom_nodes`. TARA and the BFS shot tools need
[ComfyUI-BFSNodes](https://github.com/alisson-anjos/ComfyUI-BFSNodes) as well.

This repository is synced from `backend/comfy_nodes/henge` in the Henge repository; open issues and pull requests there.
